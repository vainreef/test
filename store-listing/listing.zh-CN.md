# ZQ Text Sandbox 8F4K2 商店文案（简体中文）

## 应用名称

ZQ Text Sandbox 8F4K2

## 简短描述

快速处理文字。

## 应用描述

ZQ Text Sandbox 8F4K2 是一个本地文字处理工具。

免费功能：

* 去首尾空格
* 合并空格
* 删除重复行
* 按字母排序

Pro 功能：

* JSON 美化
* 标题格式

文字在本机处理。基础功能免费，Pro 功能需要激活码。

## 版本更新说明

首个版本：文字处理、复制结果、Pro 激活。
