# ZQ Text Sandbox 8F4K2 Store listing (English)

## Product name

ZQ Text Sandbox 8F4K2

## Short description

Fast text tools for Windows.

## Description

ZQ Text Sandbox 8F4K2 is a local text tool.

Free:

* Trim spaces
* Collapse spaces
* Remove duplicate lines
* Sort lines

Pro:

* Pretty JSON
* Title case

Text is processed locally. Free features are available at no cost. Pro features require an activation key.

First release: text tools, copy result, and Pro activation.
